SCRIPTING

Client-side vs Server-side Scripting

Client-side scripting runs in the user's browser, while server-side scripting runs on the web server.

💻

RUNS IN

Client-side

  • Runs in the web browser
  • Used for user interface interaction
  • Provides quick responses
  • Common language: JavaScript
🖥️

RUNS ON

Server-side

  • Runs on the web server
  • Processes requests and data
  • Can access databases
  • Examples: PHP, Python, Java, Node.js

SUMMARY

Putting Everything Together

The Internet and World Wide Web provide the foundation for modern online communication and information sharing. Understanding networks, URLs, domains, browsers and servers helps us understand how websites work. Client-side and server-side technologies work together to provide interactive and dynamic web applications.
